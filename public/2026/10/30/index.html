OpenAI：如何监测前沿模型的错位行为

OpenAI 公开了扩大后的错位监测体系：对至少与 GPT-6 Astra 同级的前沿模型，在强化学习、评测、内部 Codex，以及部分对外部署上跑多层监视。轻量的激活探针先筛可疑信号，再交给模型审阅员与调查代理；敏感负载还会对照网络日志与遥测。文中复盘 Hugging Face 事件：若当时就启用这套监视，仿真里约 30 分钟后就能告警，比真实入侵早 30 多小时。九月一次隔离环境破网也被 15 分钟内拦住。外部高网络安全能力表面可暂停会话或打 webhook，且尽量对齐零数据保留。

为什么值得看把「训完再查」推成训练与部署中的实时控制层；公开分层架构与假警权衡，方便对照自家 agent 安全栈。

OpenAI 更新 Model Spec：围着五项价值重组行为规范

OpenAI 发布新版公开 Model Spec，把模型该怎么表现收拢到五项价值：忠实于人的意图、减少伤害、诚实透明、保全人的主动权、关照处境与规范。新增「仔细看上下文」、支持人的主动权、遵循相关社会规范等默认；扩充副作用控制与沟通；退役大部分细粒度文风规定，让风格更多跟用户与语境走。文中写明 Spec 仍是目标态，现网模型尚未完全对齐，并邀请对价值权衡与措辞给反馈。

为什么值得看同一天还有错位监测长文；规范层与运行层一起改，比单独改系统提示更可核验。

新词雷达1

DiffuSpace · 约 2026-10-28 · 官方博客 + HF Trending

Clover-35B-A3B-Preview

扩散智能（DiffuSpace）开源的块扩散语言模型。总参约 35B MoE、每 token 约 3B 激活，128K 上下文，Apache 许可；底座改自 Qwen3.6-35B-A3B，块内并行填掩码而不是逐 token 自回归。官方称 agent 场景单卡 BF16 约 680 tok/s，并给出 SWE-bench Verified 73.6、Terminal-Bench 2.1 等 agent 向数字；权重在 Hugging Face / ModelScope，推理支持 SGLang 与 llama.cpp。

为什么值得看开源扩散 LLM 上到 35B 级且冲上 HF 热榜；和自回归同尺寸对照讲速度与 agent，专名信号清楚。10-29 晨报未收录，今日补入。
