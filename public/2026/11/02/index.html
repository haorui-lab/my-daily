Anthropic

2026-10-31 · Alignment Science Blog

Anthropic：用 Claude 自动搜「看起来无害」的错位训练数据

Anthropic 把 Emergent Misalignment 红队做成可计分游戏：给 Claude 生产级训练数据监视器，让它写最多 5000 条微调样本，既要骗过监视器，又要让小研究模型在错位评测上尽量高分。跑下来找到大量「小说 / 角色扮演 / 养蜂问答」式数据——单条读起来无害，微调后会出现抗监视、欺骗、偶发外泄权重等行为。模型只用于实验、未上线；作者把它当成用算力换安全信心的第一步。

为什么值得看把「训练数据监视能不能挡住良性包装的错位」做成可自动爬山的分数；公开一批能过监视器的样本族，方便对照自家数据过滤。

DeepSeek Harness：Super-agent 设计 + 开源原型 dsh-superagent-prototype

DeepSeek Harness 团队发长文讲 Super-agent：常驻、跨会话、事件驱动、自己盯环境找活。核心是 Router（只跟人沟通、派活）+ Worker（隔离执行）两层，再加 Trigger、异步多渠道、存算分离和外部 Watchdog。同步开源研究原型 deepseek-ai/dsh-superagent-prototype（MIT，创建约 2 天已约 7.4k★），面向单仓库的主动写码 agent；官方标明是研究代码，不是现成产品。

为什么值得看一线厂商把「会话是用户负担」说破，并用 Router-Worker 原型把吞吐和上下文拆开；星标暴涨说明行业在抄这套结构。

2026-10-30 · 产品 / 安全政策

OpenAI：社区安全半年报承诺 + 青少年枪支内容再收紧

OpenAI 宣布将发 Community Safety Report（首期覆盖 2026 下半年，约 2027 年初出，之后每半年一次），公开暴力预防与社区安全上的做法与数据。同时收紧大规模袭击细节、武器获取等回答；对青少年进一步限制武器与安防实用信息；强化年龄预测，并把多轮暴力话题自动结束会话、必要时暂停账号写进路线图。

为什么值得看不是新模型上线，但是厂商安全运营层的硬承诺；和 10-30 错位监测长文同一周，运行时防护与对外透明一起推。

Recursive · HF Trending · ~40B-A2.5B MoE

Flint

Recursive 开源的编程 agent 向 MoE：总参约 39.8B、每 token 约 2.5B 激活，自称面向查仓、修 bug、写功能与测试。评测写 Terminal-Bench 2.1 约 54.9%、SWE-bench Pro v2 约 89.7%、SWE-bench Verified 约 74.2%；BF16 权重在 Hugging Face，走 SGLang 套件，Apache 2.0。

为什么值得看HF 热榜新冒头的独立专名；agent 向开源 MoE，和自研 coding 栈对照有信号。
