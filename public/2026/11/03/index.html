OpenAI LifeVal：测 AI 能不能帮人把日常事办完

OpenAI 发布 LifeVal：按时间使用调查和约 3995 人问卷，挑出托幼、健康、教育、家务行政、理财、购物、政府办事等日常任务，用来跟踪模型在「真做事」上的进步。文中展示幼儿园择校、防汛志愿调度、找房、远程陪看球、糖尿病照护备餐等流程；作者强调要测的是个人助理能否走完工作流，而不只是聊天给建议。任务集与打分细则未公开，外部难独立复现。

为什么值得看把评测重心从知识题挪到日常生活落地；和 agent / computer use 产品线同一周对照看。

OpenAI：用激活分类器（probes）做实时安全层

OpenAI 写清已在最强模型上部署激活分类器（probes）：读中间层残差流，按 token 流式打分，超阈值立刻打断回复并拦住工具调用，再交给推理模型复核。相对文本分类器更抗部分越狱、算力更轻；局限是只能盯住标过的失败类型，换底座或权重漂太多就要重训。从 GPT-5.6 起叠进既有文本监视栈。

为什么值得看把白盒探针写进生产安全栈的方法文；和 10-29 错位监测长文同一条防线。

OpenAI Dots：接入 GPT-6 Astra / GPT-6.1 Terra 等更多前沿模型

OpenAI 的 Tibo 说正在扩大驱动 Dots 的前沿模型家族，包括 GPT-6 Astra、GPT-6.1 Terra 以及后续型号。Terra 侧重速度和人格，用来把常驻 agent 推给更多人。社区转述还提到 dot 会按任务段落自动挑模型；官方帖本身只确认扩模型和 Terra 定位。

为什么值得看常驻 agent 产品从单模型绑死走向多模型池；和 Terra 上线同一产品线的下一刀。

Hydrogen-1.0

杭州 Deep Principle 在 GLM-5.3 上做科学向后训练，放出 Hydrogen-1.0：

  • 约 753B 参数，MIT，Hugging Face / ModelScope
  • 训练吃化学、材料、生命科学领域数据，以及实验室全周期记录和发现轨迹

  • 展示聚合物 MD、反应网络、NMR 解析、材料发现等场景。

为什么值得看一线开源科学 agent 专名刚冒头；底座挂 Z.AI GLM-5.3，但发布方与专名都是新的。

LongCat-2.5

美团正式推 LongCat-2.5：

  • 约 1.6T 总参
  • 每 token 约 48B 激活
  • 原生多模态
  • 主打长程 coding / 视觉编程 / 创意设计与 3D。
  • 官方报 Terminal Bench v2.1 约 88.4、AutomationBench 约 51.8、3DCodeBench Text→3D 约 55.4
  • API 在 longcat.ai，权重暂未公开下载。
